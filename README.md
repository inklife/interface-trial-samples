# Interface studies

Three original, working interface samples made with Codex assistance for small paid design trials. These are new demonstrations, not commissioned client case studies.

- Companion conversation: two visual templates, keyboard support and local preset replies.
- Transaction operations: English demo data, local filters and a details view.
- Training app: an illustrative mobile plan and completion interaction.

All sample data and characters are illustrative. No live bank accounts, health records or AI model are connected. See each prototype for its local behavior and limitations.

Open `index.html` in a browser or use the published GitHub Pages site.
