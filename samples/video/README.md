# Mushroom motion study

[Watch the 22-second demo](mushroom-motion-demo.mp4) · [Preview](preview.png) · [Download source](mushroom-motion-source.zip)

An original self-initiated, AI-driven illustration and motion demonstration, not a commissioned client case, completed sale or competition award. The newly drawn SVG mushroom-house artwork, room names, character and captions are fictional.

The MP4 is intentionally silent: 22 seconds, 1080 × 1920, 24 fps, H.264. Motion uses camera reframing and a moving lift cabin; it does not claim character rigging. No client footage, furniture materials, stock images, downloaded music or voice recordings are included.

The source ZIP contains the original HTML/SVG, two PNG layers, Python render script, optional Playwright SVG-layer renderer and its README. Re-rendering requires Pillow, FFmpeg, FFprobe and Windows Segoe UI / Georgia fonts. Optional SVG-layer rendering also requires Node.js, Playwright and Edge. Fonts and those runtimes are referenced, not bundled. No editable timeline-project file is claimed.

The cover describes the related editing service. The demonstration itself uses this original artwork, not client-supplied assets. New service jobs require an agreed scope and assets that the buyer is allowed to use.
