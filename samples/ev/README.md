# Arrival-first EV concept

An original, self-initiated, AI-created interface demonstration inspired by a [public EV home-screen brief](https://www.freelancer.com/contest/home-screen-design-for-ev-infotainment-2791910). The concept was not entered in that competition. It is not a commissioned client case study, accepted delivery, competition award or paid project.

[Open the interactive demo](https://inklife.github.io/interface-trial-samples/samples/ev/) · [Preview both states](preview.jpg) · [Download editable source](ev-arrival-source.zip)

## Two local states

- **Normal trip:** a large arrival-reserve ring, a short reassurance line, an original schematic route and an optional backup charger.
- **Charging proposal:** the same layout with amber emphasis on a proposed stop. Accept, Dismiss and Why open explanatory local dialogs. They do not reserve a charger or modify a real route.

All vehicle, battery, route, weather, availability, price and timing figures are fictional demonstration data. The hand-drawn map is a schematic, not navigation. No measured prediction accuracy, driving experience, real-car testing, charger booking or microphone access is claimed.

## Public files

- `index.html`: standalone local HTML demo with embedded SVG, state switching and keyboard-operable controls; no external scripts or network dependency.
- `ev-normal.svg` and `ev-proactive.svg`: original layered 1920 × 1080 editable screens. Named groups separate header, arrival outcome, agent card, charging plan, map, vehicle information and persistent controls.
- `ev-normal.png` and `ev-proactive.png`: 1920 × 1080 previews of the two concept states.
- `preview.jpg`: combined state preview for the portfolio.
- `design-tokens.json`: palette, local system font references, spacing and layer names.
- `ev-arrival-source.zip`: only the public HTML, SVG, design tokens and this README. It omits internal submission notes and status files.

Every icon and map path was newly drawn. No client material, stock image, downloaded icon pack or copied UI kit is included. System Arial/Helvetica/sans-serif fonts are referenced, not distributed. The output is editable SVG and HTML, not a Figma file. The 1920 × 1080 in-car canvas scales to fit a browser; its small-screen presentation is a preview, not a validated mobile driving interface.
